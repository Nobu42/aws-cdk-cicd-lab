## 進め方

1. 第2章で環境構築・プロジェクト作成・デプロイを行う。
2. 第3・4章でTypeScriptとStep Functionsの基本を確認する。
3. 第5章でS3、メール通知、感情分析ワークフローを実装する。
4. 第6・7章でデバッグ、テスト、CI/CDを実践する。
5. 第8章の機能を本文に沿って確認する。

現在は第2章の[sampleプロジェクト](./sample/)作成、build、list、synthまで確認済みである。次は2.4のデプロイ手順を確認する。
ESLint・Prettierの導入は保留中である。作成済みプロジェクトの初期化は再実行しない。
本書の終了後は[マスタリングAWS CDK](../02-mastering-aws-cdk/README.md)へ進む。

## 記録方針

各作業を「手順・理由・確認結果」で記録する。書籍から変更する箇所は差分と理由を併記し、公式URLを該当手順のそばに置く。
サンプル雛形の作成と型チェック・テンプレート生成まで確認済みであり、AWSへのデプロイと動作テストはまだ行っていない。
