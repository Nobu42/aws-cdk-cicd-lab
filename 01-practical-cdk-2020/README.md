# 実践 AWS CDK（2020年）

[全体の学習順序へ戻る](../README.md)

## 対象書籍

『実践 AWS CDK — TypeScript でインフラもアプリも！—』
飯田橋のAWSエンジニア 著、2020年3月7日 ver 1.0。

## 進め方

1. 第2章で環境構築・プロジェクト作成・デプロイを行う。
2. 第3・4章でTypeScriptとStep Functionsの基本を確認する。
3. 第5章でS3、メール通知、感情分析ワークフローを実装する。
4. 第6・7章でデバッグ、テスト、CI/CDを実践する。
5. 第8章の機能を本文に沿って確認する。

第2章は[sampleプロジェクト](./sample/)作成、デプロイ、SNSからSQSへの受信、差分確認、CLIでの削除成功まで確認済みである。現在は第3章を実践中で、オブジェクト型のサンプルまで実行成功を確認し、クラスのサンプルも作成済みである。
ESLint・Prettierの導入は保留中である。作成済みプロジェクトの初期化は再実行しない。
本書の終了後は[マスタリングAWS CDK](../02-mastering-aws-cdk/README.md)へ進む。
